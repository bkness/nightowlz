Unused logo mark experiments

These are alternate logo mark components for visual testing only.
They are intentionally not wired into app screens yet.

Files

- BrandMarkAltCircle.js: winged mug inside double neon ring
- BrandMarkAltBadge.js: round badge with side wings
- BrandMarkAltPin.js: map-pin neon mark with winged mug core
- BrandMarkAltArc.js: arc ring with airplane-wing silhouette
- BrandMarkAltFeather.js: feather-wing badge variant

How to test quickly

1. Import one into a screen (for example Auth or Discover):
   import BrandMarkAltCircle from "../../components/unused/logo-marks/BrandMarkAltCircle";
2. Render it where BrandMark is used.
3. Pick favorite and I can swap it in globally.
