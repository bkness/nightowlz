Features

Built for the night

🔍

Search Any City

Find bars, clubs, live music, and entertainment in any city. Powered by OpenStreetMap Overpass API.

🗺️

Apple Maps Integration

Every venue has a live map view and one-tap directions via Apple Maps.

🧡

Save Your Favorites

Build your personal shortlist of go-to spots. Your bars sync to your account across sessions.

🦉

User & Owner Accounts

Sign up as a nightlife fan or a venue owner. JWT auth keeps everything secure.

📅

Events — Coming Soon

Real-time event drops for live music, karaoke, trivia, and more at your saved spots.

🌙

Dark Mode Native

Designed for the night. Dark-first UI built in React Native with a custom neon theme system.
